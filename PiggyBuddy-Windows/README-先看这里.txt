抱猪提醒 · Windows 桌宠版 2.0

【怎么启动】
1. 如果旧版小猫程序还在运行，请先退出，并取消旧版的登录自启动。
2. 完整解压本压缩包。不要在压缩包内直接运行。
3. 双击 Start.cmd（也可以双击“启动桌宠.cmd”）。
4. 第一次会用 Windows 自带的 .NET Framework C# 编译器运行计时自检并生成 EXE，随后出现桌宠。
5. 之后双击同一个启动文件会直接运行已生成的 EXE。
不需要管理员权限，不需要安装 Python、Node.js 或 Visual Studio，不需要联网。

首次启动需要标准 Windows 10 的 .NET Framework 4.x 组件。系统被精简、企业策略限制或相关组件损坏时可能无法启动。
程序生成位置：%LOCALAPPDATA%\PiggyBuddy\PiggyBuddy-v2.0.exe
可给这个 EXE 创建桌面快捷方式。

【先设置一次】
点击桌宠下方 ⚙ 或双击人物，打开设置：
- 工作时间：1–240 分钟；活动时间：1–60 分钟。
- 工作结束自动开始活动计时，活动结束自动开始下一轮。
- “提醒方式”中可以多选以下 6 项：
  ① 系统提示音或自定义 WAV
  ② 中文语音播报，可调语音音量
  ③ Windows 托盘气泡
  ④ 桌宠对话气泡
  ⑤ 挥手姿态＋轻轻跳动
  ⑥ 独立置顶提醒窗口
- 可以修改提醒内容，点击“预览提醒”体验当前勾选组合，再保存。
- “桌宠与启动”中勾选“登录 Windows 后自动启动”，以后登录时自动出现。
- 桌宠大小支持 65%–150%，可关闭始终置顶。

【日常操作】
拖动人物：移动桌宠，自动记住位置。
点击人物：简单对话。
双击人物：打开设置。
Ⅱ / ▶：暂停 / 继续，保留本轮剩余时间。
−：收到系统托盘，仍继续计时；双击托盘图标找回。
右键人物：设置、暂停、重新开始、稍后 5 分钟、隐藏、退出。
右键托盘图标：找回桌宠、设置、退出等。
“稍后 5 分钟”把本轮切换为 5 分钟工作倒计时，结束后再次提醒活动。
关闭提醒窗口不停止自动循环。
如多屏切换后找不到桌宠：从托盘打开设置→桌宠与启动→找回桌宠到主屏幕。

【计时规则】
默认工作 45 分钟，活动 5 分钟。
单轮倒计时使用单调时钟，不受手动调整系统时间影响。
可启用每日时段，比如 09:00–22:00；支持跨午夜，起止相同表示全天。
时段之外挂起计时，在时段内继续。时段限制不影响手动预览。
电脑睡眠或长时间挂起后（更新间隔超过 90 秒），自动重新开始工作轮，不集中补弹提醒。
电脑关机或睡眠时无法即时提醒。
重新打开程序从工作轮开始；如果退出前手动暂停，下次仍保持暂停。
修改时长并保存会重新开始工作轮；只更改提醒方式、大小等不会重置倒计时。
今日完成轮数只在本次运行中记录，重启或跨日清零。
此版不是逐帧行走动画：使用两张透明姿态图，加呼吸、跳动动画。

【声音与通知】
中文语音使用 Windows 已安装的中文语音，不模仿照片人物的声音。
未安装中文语音时，预览会显示具体提示，可先使用其他提醒方式。
Windows 专注助手、静音和系统通知设置可能抑制声音或托盘气泡。
自定义音效使用 WAV；声音大小由系统音量控制，设置中的滑块仅控制语音音量。
本软件不锁屏、不限制键盘鼠标、不强迫关闭其他程序。

【卸载 / 停止自启动】
1. 在设置中取消“登录 Windows 后自动启动”，保存。
2. 右键托盘图标退出。
3. 删除 %LOCALAPPDATA%\PiggyBuddy 文件夹及解压文件夹。
如果程序无法启动，可在 Windows 任务管理器的“启动”页禁用 PiggyBuddy。
程序只使用当前用户的启动项：HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PiggyBuddy。
不修改 PowerShell 执行策略，不添加后台服务。

【遇到问题】
首次编译失败：启动窗口会打开 %LOCALAPPDATA%\PiggyBuddy\build.log。
运行错误：查看同目录的 error.log。
把错误文本或截图发回即可定位。
设置文件是同目录的 settings.xml；损坏时加载默认设置。
如果要重新生成程序：退出桌宠，删除 PiggyBuddy-v2.0.exe，再启动 Start.cmd。

【验证情况与首次试用】
已检查：C# 语法树、XAML 与命名控件引用、XML、透明素材及打包文件。
首次本机启动会先编译并执行 11 项计时逻辑自检，通过才生成桌宠程序。
当前制作环境不具备 Windows 桌面运行条件；尚未完成 Windows 实机编译和界面运行验证。
请首次设为工作 1 分钟、活动 1 分钟，确认提醒与下一轮；然后测试暂停、隐藏到托盘、各提醒预览、登录自启动。
这是一版本机生成的可试用程序包，不是已签名的安装程序。

【隐私与素材】
程序运行全程离线。配置只保存到当前 Windows 用户目录。
两张参考照片用于生成 Q 版人物，压缩包不包含原始照片。
桌宠素材由内置 imagegen 根据照片生成；提示词见 source\asset-prompt.txt。
